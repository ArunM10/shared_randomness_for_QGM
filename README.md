# Shared Randomness for Quantum Generative Models

This repository contains the code and numerical data used in the paper **“Representational separation between unitary and channel quantum generative models via shared classical randomness at shallow depth.”**

The scripts reproduce the numerical comparison between shallow unitary Born models and models augmented with shared classical randomness.
